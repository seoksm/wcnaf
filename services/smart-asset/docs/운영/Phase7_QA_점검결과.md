## 남은 항목 (규모가 커서 별도 우선순위 논의 필요 - 이번에는 미착수)

### 브레이크포인트 전환 — 나머지 FAIL/PARTIAL
- **P-1 목록 → 모바일 카드뷰**: 어떤 목록 화면도 <768에서 카드로 전환하지 않는다(전부 AG-Grid 그대로).
- **트리+상세(P-4) → 드릴다운**: 조직도·메뉴관리 모두 <768에서 트리+상세가 세로로만 쌓이고 전환되지 않는다.
- **임직원 하단 탭**: `WiniBottomNavigation` 컴포넌트 자체가 실제 화면 어디에도 쓰이지 않는다 - 임직원 화면은 전부 관리자와 같은 드로어 레이아웃을 쓴다.
- **폼(P-3) 하단 고정 액션바**: 어떤 등록/수정 폼에도 sticky/fixed 액션바가 없다.
- **칸반 모바일 대체**: 드래그 비활성은 맞지만, 상태 탭이 아니라 드롭다운 필터 + 동일한 데스크톱용 AG-Grid를 그대로 씀.
- **라이선스 상세 5탭**: 전제 자체가 다름 - 실제로는 탭이 없고 세로 스크롤 하나로 단순화돼 있음(의도된 설계 변경, S-512와 동일 패턴).

### 업로드·다운로드
- 엑셀 SXSSF 스트리밍 미구현(읽기/쓰기 모두 전체 메모리 로딩) - 2,000행에서 실측 타임아웃 테스트 없음.
- 검증 오류가 행번호+자산코드+메시지 3필드뿐 - "컬럼명"과 "입력값"이 별도 필드로 없음.
- "오류 1건이라도 있으면 전량 롤백"이 설계 요구사항인데, 실제 구현은 행별 독립 트랜잭션(부분 성공) - `엑셀_업서트_멱등성.md`에 의도적 트레이드오프로 문서화돼 있어 **제품 결정이 필요**(스펙을 바꿀지, 구현을 바꿀지).
- HEIC 업로드 미지원(공용 업로드 확장자 화이트리스트에 heic/webp 자체가 없음) - 새 의존성(HEIC 디코더) 필요.

### 권한·프로세스 분기
- 프로세스 On/Off → UI 9개 지점 매트릭스가 사실상 전부 미연동(9곳 중 9곳 FAIL) - LNB·임직원탭·자산상세액션·QR액션·알림유형 등 어디에도 `processConfig` 참조가 없음.
- C2(진행 중 건수 있으면 끄기 차단)는 `프로세스_설정.md`에 이미 "미구현"으로 문서화된 기존 갭.

### 알림 (6개 전부)
