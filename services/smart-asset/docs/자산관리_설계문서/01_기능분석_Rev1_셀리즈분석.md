# 셀리즈(Sellease) 서비스 기능 분석 — 관리자용 / 임직원용

> 출처: 셀리즈 서비스 고객지원 포털 (Notion) 전체 가이드 문서 33건 분석
> 분석일: 2026-09-07
> **범위 제한: 엔터프라이즈 플랜 전용 기능은 모두 제외** (베이직 / 비즈니스 플랜 범위만 포함)

## 0. 서비스 개요

셀리즈는 기업의 **유형자산 + 무형자산(라이선스·구독·렌탈)**을 통합 관리하는 SaaS형 자산관리 솔루션이다.
핵심 설계 사상은 세 가지로 요약된다.

| 설계 사상 | 시스템적 함의 |
|---|---|
| **QR코드가 자산의 물리적 식별자** | 모든 자산 = 1 QR. 실사·대여·반납·조회·수리요청의 단일 진입점 |
| **관리 업무를 임직원에게 분산** | 관리자 단독 실사가 아닌 "임직원 참여형" 프로세스. 별도 임직원 포털 존재 |
| **프로세스 On/Off 모듈화** | 대여 / 수령·반납 확인서 / 예산(마일리지) 프로세스를 기업별로 켜고 끄는 구조 |

**사용자 역할(권한) 5단계** — 시스템 권한 모델의 기준축

| 권한 | 범위 |
|---|---|
| 최고관리자 | 워크스페이스 소유자, **1명 한정**, 전 기능 접근, 위임 가능 |
| 관리자 | 최고관리자로부터 위임. 자산 + 멤버 관리 |
| 자산관리자 | 자산 관리 전담 |
| 부서자산관리자 | **조직도 기준 자기 부서 + 하위부서**의 유형자산·멤버·불용자산·전수조사만 |
| 임직원 | 본인 할당 자산 / 본인 라이선스 / 본인 생성 티켓만 조회 |

> 별도로 **메뉴 접근권한(Menu ACL)** 이 권한과 직교하게 존재. 관리자 계정별로 노출 메뉴를 체크박스로 제어하며, 체크 해제 시 전사 미노출(= 메뉴 모듈화). 임직원에게는 여기서 `유형자산-가치 조회`, `QR 조회권한(타인 자산 스캔 + 수리요청 생성)` 2개 옵션 권한을 추가 부여 가능.

# PART 1. 관리자용 서비스

## 1-1. 대시보드

| 기능 | 상세 |
|---|---|
| 현황 시각화 | 유형자산 상태별 / 종류별 / 위치별 현황 |
| 비용 시각화 | 구독·렌탈 월별 비용, 라이선스 지출내역 |
| 만료 예정 | 무형자산 만료 예정 자산 집계 |
| 전수조사 현황 | 임직원 참여율, 신규 발견 자산 |
| 개인화 | 표시 항목 체크박스 On/Off, 실시간 갱신 |
| 인터랙션 | 원형차트 범례 클릭 → 해당 자산 드릴다운, 선차트 툴팁 |

**전제조건**: 자산 0건이면 대시보드 비활성 상태 화면 노출.

## 1-2. 유형자산 관리

### (1) 자산 등록 — 4가지 경로
| 경로 | 설명 |
|---|---|
| 엑셀 대량 등록 | 자산종류별 양식(유형/무형/라이선스/불용/렌탈/법인차량/소모품) 다운로드 → 업로드. **자산코드가 신규/갱신 판단 키** |
| AI 자산 등록(단건) | 사진 촬영 → AI가 모델명·제조사·사양 자동 추출. 사진 최대 4장 |
| 자산 복사 | 동일 사양 자산 최대 100개 복제. 모델명 뒤 `-1, -2` 자동 채번 |
| 에이전트 자동 수집 | PC 에이전트 설치 시 CPU/RAM/HDD 등 사양 포함 자동 등록. **수기 등록분과 병합(merge) 기능 제공** |

### (2) QR코드
- 등록 시 **자동 생성**
- 출력: 일반 A4 라벨지(12분할/96분할/방수형) 4종 포맷 + 라벨 전용 프린터(브라더) 연동
- 개별 출력 시 라벨 디자인 3종(기본형/문구형/심플형)
- 회사 로고 삽입 (**비즈니스 플랜 이상**)
- 서비스 내 라벨지 구매 링크 제공

### (3) 조회·수정
- 자산 상세 + **히스토리 탭**(변경 이력, 활동 로그 자동 기록)
- QR 스캔 → 즉시 상세 조회
- 체크박스 다중선택 → **일괄 변경**

### (4) 커스터마이징 (멀티테넌시 설정 축)
| 대상 | 내용 |
|---|---|
| 종류(카테고리) | 사용자 정의 추가/순서변경/**다국어 명칭**. 모니터·데스크탑PC·노트북·기타는 기본값(수정·삭제 불가) |
| 위치 | 층/지사/건물 단위 자유 정의. '본사'는 기본값(수정·삭제 불가, 최하단 이동으로 숨김) |
| 필드 | 사용자 정의 필드 자유 추가 |
| 자산코드 | 자동 채번 / 수기 입력(외부 ERP 코드 체계 수용) 선택 |
| 목록 | 컬럼 순서 드래그 변경, 표시 여부 토글 |

### (5) 감가상각
- 기준 연/월 지정 조회, **엑셀 다운로드(회계감사용)**
- 자산 종류별 내용연수·잔존가치(%) 설정 → **정액법 자동 계산**
- 회계기준 선택: **K-GAAP / IFRS(K-IFRS)**

### (6) 불용자산
- 유형자산 목록 또는 상세에서 `불용처리` → 유형자산 모수에서 제외, **감가상각 대상 제외**, 별도 카테고리 관리
- 상태 흐름: `처분대기`(창고 보관) → `처분완료`(매각/폐기/무상기증)
- **처분완료 시 수정 불가** (처분대기 상태에서만 수정 가능)

## 1-3. 전수조사(자산실사)

두 가지 모드가 존재하며, 시스템 설계상 별도 프로세스로 분리되어 있다.

### (A) 임직원 전수조사 (권장)
관리자 시행 → 대상 임직원 전원 이메일 + 카카오톡 발송 → 임직원이 자기 자산 QR 스캔·촬영 → 자동 리포트

**생성 시 설정 항목**
- 제목 / 시작일·종료일 / 검수자(복수 지정)
- 참여 부서 · 참여 임직원 (부서 선택 시 소속 임직원 자동 선택)
- 대상 종류 / 위치 필터
- `자산 사진 촬영 필수` — 업로드 차단·현장 촬영만 허용(허위 실사 방지)
- `리마인드 메일 자동 발송` — 매일 09:00 미완료자 대상
- `임직원 자산 수정 허용`
- `임직원 신규 자산 등록 허용`
- `임직원 전수조사 완료 버튼 노출` 여부

**제약(설계 시 반드시 반영)**
- 시작 후 참여 대상 변경 불가
- 동일 임직원의 중복 전수조사 참여 불가

### (B) 관리자 전수조사
자산관리자 이상이 직접 현장 QR 스캔. 제목/기간/검수자(복수)/검수항목(대상 자산 선택)만 설정.

### (C) 공통
- 자동화: 월/분기 등 **반복 주기·날짜·대상 사전 지정 시 자동 시행**
- 실사 결과 실시간 클라우드 저장, 완료/미완료 현황 모바일 확인
- 완료 처리 → **전수조사 리포트 다운로드 / 인쇄(PDF)**
- 상태값 변경·메모 기록 지원
- ※ iPhone은 기본 카메라 앱 필수(외부 QR 앱은 로그인 세션 미유지)

> ⛔ 제외: 전수조사 **AI 검수 기능**(사진-자산정보 일치도 분석)은 엔터프라이즈 전용

## 1-4. 대여 관리 (프로세스 On/Off)

- `유형자산 > 프로세스 설정 > 대여 프로세스 적용 ON`
- 자산 상태를 `대여`로 설정(개별 / 일괄 변경)
- 대여 전용 위치(예: 공용창고, 로비 공유존) 커스텀 권장
- 임직원 QR 스캔 대여 → **대여자·대여상태 실시간 자동 기록**, 반납도 QR 재스캔
- 대여 이력 자동 축적
- ⚠️ 임직원이 "조회 권한 없음" 오류 시 → 메뉴접근권한에서 임직원 `QR스캔 조회` 체크 필요

## 1-5. 수령 / 반납 확인서 (프로세스 On/Off)

- `프로세스 설정 > 수령확인 프로세스 ON`
- 요청 진입점: **유형자산 상세** 또는 **멤버 상세** (자산에 사용자 지정 시 대상자 자동 세팅)
- 요청 → 임직원 이메일 발송 → 로그인 → 문서 확인 → **디지털 서명** → 완료
- 기발송 자산 표시로 중복 발송 방지
- **타임스탬프 포함 영구 보관** (페이퍼리스 증빙)
- 반납 확인서는 **담당자 서명까지 완료되어야 최종 반납 처리**
- 반납 후 완료 상태값·위치 추가 설정 가능
- 확인서 내부 안내문구 회사 규정에 맞게 커스텀 가능
- 미서명 자산은 임직원 화면에서 자산 정보 조회 차단

## 1-6. 예산(마일리지) 관리 프로세스 (프로세스 On/Off)

- `프로세스 설정 > 마일리지 설정` (**선행조건: 조직도·멤버 등록 완료**)
- **1 마일리지 = 1원**
- 배분 축: 부서별 / 직급별 / 개인별
  - `초기 마일리지` — 신규 멤버 등록 시 자동 할당
  - `월별 적립` — 매월 지정일(1일) 자동 충전
- 임직원 구매 신청 → **서비스데스크 티켓(예산 사용) 자동 생성**
- 관리자 티켓 완료 처리 → **해당 금액으로 유형자산 자동 등록**
- 티켓 코멘트·상태 변경 시 알림 메일 발송

## 1-7. 무형자산 관리

| 영역 | 기능 |
|---|---|
| 무형자산 | 도메인·보안인증서·특허 등 등록. 알림 대상자 복수 지정(이메일/카카오톡), 만료 **1·3·7·30일 전**(문서상 최대 90·180일 옵션 언급) 알림 |
| 조치 관리 | 만료 예정 자산 상태 업데이트, 갱신일 입력·만료일 연장, 조치 이력 자동 저장 |
| 렌탈 관리 | 구독·렌탈 자산 목록화, 과금방식·결제주기·계약기간 기록, 다음 결제일·결제상태 추적, 결제일 전 담당자 자동 알림, 자산별 지출내역 + 대시보드 집계 |

※ 카카오톡·문자 알림은 `멤버 상세 > 휴대번호` 입력 필요.

## 1-8. 라이선스 관리

- 라이선스 목록·보유현황·비용 추적
- 등록: **셀리즈 소프트웨어 DB 자동완성 검색**(미검색 시 수기 입력, 한글 실패 시 영문 시도)
- 구매정보: 구매·계약일자 **복수 등록**, 수량·평균비용 기준 총 구매내역 자동 계산
- 사용자 배정: 멤버 지정, 구매내역과 연결하여 할당 수량 확인
- 포함 소프트웨어(서브 SW) 등록 — 예: Adobe CC → Photoshop, Illustrator
- 지출내역: 월 자동결제 선택 시 자동 기입, 아닐 경우 수기 등록 → 대시보드 반영
- 공급사 정보: 공급사명·담당자·연락처·계약 메모
- 만료 알림 설정

> ⛔ 제외: **라이선스 비용 최적화**(사용량 기반 절감액 산출) — 엔터프라이즈 전용

## 1-9. 서비스 데스크

- **칸반보드** 기반 워크플로우 (접수대기 → 접수 → 처리중 → 완료)
- 티켓 유형: 신규 구매, 수리, 교체, 연장, 폐기, 예산 사용
- `나에게 할당된 티켓 보기` 필터
- 상태 변경 시 요청자 자동 메일 발송
- 코멘트 기반 커뮤니케이션
- **자산 상세 ↔ 티켓 히스토리 연동** (해당 자산의 모든 티켓 이력 추적)
- `완료된 티켓` 별도 탭 — 리포트 작성 참고자료
- ⚠️ **완료된 티켓은 수정 불가**

| 보안설정 | **2단계 인증** — 대상 관리자 선택, 인증코드 메일 발송. **관리자급만 적용 가능** |

> ⛔ 제외: AI 에이전트 설정(이름·인사말·커스텀 학습데이터·민감정보 필터링·토큰 사용량) — 문서상 "비즈니스 플랜 이상"으로 표기되나, AI 에이전트 본체 가이드는 **엔터프라이즈 플랜**으로 표기되어 상충. 도입 시 벤더 확인 필요 항목.

# PART 2. 임직원용 서비스

임직원 포털은 **관리자 화면과 완전히 분리된 별도 UI**이며, 모바일 우선(QR 스캔 필수)으로 설계되어 있다.
메뉴는 **홈 / 내 자산 / 대여자산 / 서비스데스크** 4개로 고정.

## 2-1. 가입 및 진입

| 경로 | 흐름 |
|---|---|
| 초대 메일 + 소셜 계정(Google/MS) | 링크 클릭 → 소셜 로그인 → 입장 |
| 초대 메일 + 일반 이메일 | 회원가입 → 비밀번호 설정 → 이름·닉네임 설정 → 입장 |
| 관리자 직접 등록 | 초대메일 없음. 관리자가 전달한 ID/초기 비밀번호로 바로 로그인 |

## 2-2. 홈

- 지급받은 자산 개수 (클릭 → 내 자산 이동)
- 대여 중인 자산 목록(대여 프로세스 활성 시)
- **서명 대기 중인 수령/반납 확인서**
- **전수조사 진행률** (복수 전수조사 동시 참여 가능)
- **마일리지 현황** — 사용/잔여, `자산 구매 신청`, `마일리지 사용 현황 보기`
- ※ 표시 항목은 회사 설정(활성 프로세스)에 따라 가변

## 2-3. 내 자산

**유형자산 탭**
- 지급받은 자산 목록·상세 조회
- **엑셀 다운로드**
- 조회 가능 범위: 기본정보, 추가정보, 수령/반납확인서, 히스토리(대여기록·메모)
- 수정 가능 범위: **이미지 등록·삭제, 메모 등록·삭제만**. 그 외 조회 전용
- 자산 상세 우측 상단 `수리 요청` → 티켓 생성
- 본인 자산 QR 스캔 조회 가능
- (옵션 권한) `유형자산-가치` 부여 시 취득가액 조회 가능

**라이선스 탭**
- 지급받은 라이선스 조회
- **미사용 라이선스 회수 요청** 기능

## 2-4. 대여자산

1. 대여 가능 자산 목록 조회 (모바일 브라우저 권장)
2. 자산명 클릭 → 위치·사양·상태 상세 확인
3. 자산 부착 QR 스캔 → 링크 접속
4. 팝업에서 `대여하기` 클릭 → 대여 완료
5. `내 대여자산` 목록 및 홈 대시보드에서 확인
6. 반납: **원위치 반납 후 QR 재스캔** → 자동 반납 처리

## 2-5. 전수조사 참여

1. 안내 메일 수신 → `참여하기` → 임직원 화면 진입
2. 대상 자산에 "전수조사 대상 / QR 확인 필요" 표시
3. `QR 검수하기` → 자산 QR 촬영 → 자동 인식·검수 완료
4. 자산 사진 촬영 (관리자가 `촬영 필수` 설정 시 현장 촬영만 허용)
5. 이상 시 **상태값 변경 / 메모 추가**
6. 신규 자산 발견 시 `AI 자산등록` — 사진 촬영 → AI 분석 → 정보 자동 기입
   - **전수조사 기간 중에만 등록 가능**, 기간 중 본인이 수정·삭제 가능
7. 완료 자산에 체크 아이콘 → `전수조사 완료하기`
   - 단, 관리자가 `완료 버튼 노출`을 껐다면 임직원 직접 완료 불가
8. 홈에서 진행률 확인

※ 다음 자산 스캔 시 카메라 앱 ↔ 브라우저 전환 필요 (OS별 앱 전환 안내 제공)

## 2-6. 자산 수령 / 반납 확인서

1. 담당자 요청 → 안내 메일 수신
2. `수령 확인서 동의하기` → 서명 페이지
3. 문서 확인 → **서명 작성** → 동의 → 완료
4. 서명 완료 안내 메일 수신, 메일에서 문서 재확인 가능
5. 반납 확인서도 동일 절차. 단 **담당자 서명 완료 후 최종 반납 처리**
6. 서명 대기 문서는 홈 탭에서 확인

⚠️ **미서명 자산은 서명 전까지 자산 정보 조회 불가** — 서명 강제 장치

## 2-7. 서비스 데스크

| 유형 | 흐름 |
|---|---|
| 신규 자산 구매 | 서비스데스크 → 티켓 등록 → 세부정보 입력 → 등록 |
| 수리·교체 | 내 자산 목록에서 자산 선택 → `수리 요청` 또는 **QR 스캔으로 간편 신청** |
| 마일리지 구매 | 홈 → `자산 구매 신청` → **잔여 마일리지 범위 내에서만** 신청 → 티켓 자동 생성 |

- 상태 변화(접수대기 → 접수 → 완료) 시마다 메일 알림
- 티켓 상세 하단 **코멘트**로 담당자와 소통 (라이선스 키 등 전달 경로)
- 완료 시 완료 메일 → 자산 수령
- 구매 완료 시 신청 금액만큼 마일리지 자동 차감

## 2-8. PC 에이전트 (임직원 관점)

- 로그인 → 우측 상단 프로필 → `PC 에이전트 다운로드` → OS별 설치파일
- Windows: `SelleaseAgentSetup.exe` / macOS: `.dmg` → 응용프로그램 폴더 D&D
- 부여받은 계정으로 로그인 → 트레이/메뉴바 상주, 자동 실행
- 트레이 메뉴: 장치정보 업데이트 / 홈페이지 / 권한 갱신 / 원격 신청하기 / 업데이트 확인
  - ※ 원격지원 메뉴는 권한 부여 + `권한 갱신` 후 노출 (원격지원 자체는 엔터프라이즈)

# PART 5. 자산관리 시스템 구축 관점 시사점

## 5-1. 도메인 모델 핵심 엔티티

```
Workspace(Company)
 ├─ Member ── Role(5단계) ── MenuACL
 │   └─ Department (조직도, 계층형 → 부서자산관리자 권한 범위 결정)
 ├─ TangibleAsset ── AssetCode / QR / Category / Location / CustomField
 │   ├─ DepreciationRule (내용연수, 잔존가치, K-GAAP|IFRS)
 │   ├─ AssetHistory (변경이력·활동로그)
 │   ├─ Loan (대여/반납 트랜잭션)
 │   ├─ Acknowledgement (수령/반납 확인서 + 서명 + 타임스탬프)
 │   └─ DisposalAsset (불용 → 처분대기 → 처분완료)
 ├─ IntangibleAsset ── ExpiryAlertRule (알림대상 N명, D-1/3/7/30)
 ├─ RentalAsset ── PaymentSchedule / ExpenseRecord
 ├─ License ── PurchaseRecord(1:N) / AssignedUser(1:N) / SubSoftware(1:N) / Vendor
 ├─ Inventory(전수조사) ── InventoryTarget / InventoryResult / InventoryReport
 ├─ Ticket (ServiceDesk, 칸반 상태머신) ── Comment ── Asset 연결
 ├─ Mileage ── Allocation(부서|직급|개인) / Transaction
 └─ ProcessConfig (대여 / 수령반납 / 예산 On·Off)
```

## 5-2. 벤치마킹 시 반드시 반영할 설계 포인트

1. **QR = 무인증 진입점이 아님.** 스캔 후 로그인 세션 검증 → 권한에 따라 조회 범위 분기. iOS 기본 카메라 외 앱은 세션 유지 실패 → 웹 세션 설계 주의.
2. **프로세스 On/Off 플래그**를 워크스페이스 설정으로 두어 화면·메뉴·홈 위젯이 동적으로 구성된다. 임직원 홈은 활성 프로세스의 함수.
3. **권한 = 역할(5단계) × 메뉴 ACL** 이원 구조. 부서자산관리자는 조직도 트리 기반 데이터 스코프(row-level security)가 필요.
4. **불변성 규칙**: 완료된 티켓 수정 불가, 처분완료 자산 수정 불가, 전수조사 시작 후 대상 변경 불가, 서명 문서 영구 보관. → 상태머신에 잠금 규칙을 명시적으로 설계.
5. **알림 채널 다중화**: 이메일 + 카카오톡/SMS(휴대번호 등록 시) + Slack(채널별 알림유형 매핑). 알림 유형과 채널의 N:M 매핑 테이블 필요.
6. **IdP 동기화(Google/Entra)**: 일 1회 배치(04:00), 덮어쓰기 정책·삭제 동기화 정책을 옵션화. 동기화 생성 계정의 기본 권한은 최하위(임직원).
7. **자산코드가 업서트 키**. 외부 ERP 코드 체계 수용을 위해 자동채번/수기입력 선택형으로 설계.
8. **자산 병합(merge)**: 수기 등록분과 에이전트 자동수집분의 중복 해소 로직이 실무상 필수.
