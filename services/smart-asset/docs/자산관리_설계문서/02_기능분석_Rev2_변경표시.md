## 0. 서비스 개요

~~셀리즈는~~ 🔵 **[변경 R2]** 본 시스템은 기업의 **유형자산 + 무형자산(라이선스·구독·렌탈)**을 통합 관리하는 ~~SaaS형~~ 🔵 **[변경 R8/R9]** **사내 웹 기반** 자산관리 솔루션이다.
핵심 설계 사상은 세 가지로 요약된다.

| 설계 사상 | 시스템적 함의 |
|---|---|
| **QR코드가 자산의 물리적 식별자** | 모든 자산 = 1 QR. 실사·대여·반납·조회·수리요청의 단일 진입점 🟢 **[추가 R9]** 스캔은 **모바일웹 브라우저(getUserMedia + JS 디코더)** 로 구현 — 전용 앱 설치 불필요 |
| **관리 업무를 임직원에게 분산** | 관리자 단독 실사가 아닌 "임직원 참여형" 프로세스. 별도 임직원 포털 존재 |
| **프로세스 On/Off 모듈화** | 대여 / 수령·반납 확인서 ~~/ 예산(마일리지)~~ 🔵 **[변경 R6]** **2개 프로세스**를 기업별로 켜고 끄는 구조 |

**사용자 역할(권한) 5단계** — 시스템 권한 모델의 기준축 *(변경 없음, 그대로 채택)*

| 권한 | 범위 |
|---|---|
| 최고관리자 | 워크스페이스 소유자, **1명 한정**, 전 기능 접근, 위임 가능 |
| 관리자 | 최고관리자로부터 위임. 자산 + 멤버 관리 |
| 자산관리자 | 자산 관리 전담 |
| 부서자산관리자 | **조직도 기준 자기 부서 + 하위부서**의 유형자산·멤버·불용자산·전수조사만 |
| 임직원 | 본인 할당 자산 / 본인 라이선스 / 본인 생성 티켓만 조회 |

> 별도로 **메뉴 접근권한(Menu ACL)** 이 권한과 직교하게 존재. 관리자 계정별로 노출 메뉴를 체크박스로 제어하며, 체크 해제 시 전사 미노출(= 메뉴 모듈화). 임직원에게는 여기서 `유형자산-가치 조회`, `QR 조회권한(타인 자산 스캔 + 수리요청 생성)` 2개 옵션 권한을 추가 부여 가능. **→ 유지**

## 1-4. 대여 관리 (프로세스 On/Off) *(전체 채택)*

- `유형자산 > 프로세스 설정 > 대여 프로세스 적용 ON`
- 자산 상태를 `대여`로 설정(개별 / 일괄 변경)
- 대여 전용 위치(예: 공용창고, 로비 공유존) 커스텀 권장
- 임직원 QR 스캔 대여 → **대여자·대여상태 실시간 자동 기록**, 반납도 QR 재스캔
- 대여 이력 자동 축적
- ⚠️ 임직원 "조회 권한 없음" 오류 → 메뉴접근권한에서 임직원 `QR스캔 조회` 체크 필요

## 5-2. 설계 포인트 (개정 반영)

1. **QR = 무인증 진입점이 아님.** 스캔 후 로그인 세션 검증 → 권한에 따라 조회 범위 분기. ~~iOS 기본 카메라 외 앱은 세션 유지 실패 → 웹 세션 설계 주의.~~
   🟢 **[추가 R9]** **웹 내장 스캐너(getUserMedia + jsQR/BarcodeDetector)** 방식이면 동일 브라우저 세션 안에서 처리되므로 이 문제가 원천 소멸. **단, iOS Safari는 HTTPS + 사용자 제스처 후에만 카메라 허용**되므로 전 구간 HTTPS 필수.
2. **프로세스 On/Off 플래그**를 워크스페이스 설정으로 두어 화면·메뉴·홈 위젯이 동적으로 구성된다. 🔵 **[변경 R6]** 대상은 **대여 / 수령·반납 2종**.
3. **권한 = 역할(5단계) × 메뉴 ACL** 이원 구조. 부서자산관리자는 조직도 트리 기반 데이터 스코프(row-level security) 필요. **→ 그대로 채택**
4. **불변성 규칙**: 완료 티켓 수정 불가, 처분완료 자산 수정 불가, 전수조사 시작 후 대상 변경 불가, ~~서명 문서~~ 🔵 **승인 이력** 영구 보관. → 상태머신에 잠금 규칙 명시.
5. ~~**알림 채널 다중화**: 이메일 + 카카오톡/SMS + Slack. 알림 유형과 채널의 N:M 매핑 테이블 필요.~~
   🔵 **[변경 R3] 알림 채널 단일화**: **사내 메신저 1채널**. 다만 **알림 유형 ↔ 수신 대상(개인 DM / 관리자 채널) 매핑 테이블은 유지**하고, 발송 실패 재시도·발송 이력 테이블을 함께 설계. 향후 채널 추가를 대비해 **발송 어댑터 인터페이스로 추상화**할 것.

   🟢 **[추가 R7]** 대신 **인사 데이터 엑셀 일괄 등록/갱신 배치**를 운영 절차로 규정. 퇴사자 계정 비활성 누락이 최대 리스크.
