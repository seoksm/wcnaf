## §1 대시보드 위젯 — 형태를 먼저 정한다

원본 기능정의서는 대시보드를 “원형차트·선차트”로 기술했다. 그런데 데이터의 일(job)이 형태를 결정 해야 하고, 그 기준으로 다시 보면 상당수가 차트가 아니거나 다른 차트여야 한다.

> ⚠️ 원형차트를 쓰지 않는다. 자산 종류가 7개인데 파이로 그리면 순위 비교가 불가능 하다. 사람은 부채꼴 면적을 비교하지 못한다. 종류별 현황의 일은 “어느 종류가 많은가”이므로 가로 막대(정렬된) 가 정답이다.  
> 그리고 만료 예정 자산은 차트가 아니라 표 다. 이 위젯의 일은 “분포를 보여주기”가 아니라 “무엇을 지금 처리해야 하는가” 이므로, 개수와 목록이 필요하다.

| 위젯 | 데이터의 일 | 형태 | 색 역할 | 원본 대비 |
|---|---|---|---|---|
| 자산 총계 | 헤드라인 숫자 4개 | KPI 스탯 타일 (취득가액·상각누계·장부가·자산수) | 없음 (텍스트) | 신설 |
| 종류별 현황 | 매그니튜드 비교 | 가로 막대 · 값 내림차순 | 단일 색조 (sequential) | ⚠ 원형차트 → 가로막대 |
| 위치별 현황 | 매그니튜드 비교 | 가로 막대 · 값 내림차순 | 단일 색조 | ⚠ 원형차트 → 가로막대 |
| 상태별 현황 | 부분-전체 + 상태 | 단일 누적 막대 (1줄) + 범례 | 상태색 (good/warn/critical) | ⚠ 원형차트 → 누적막대 |
| 월별 비용 추이 | 시간 추세 · 계열 3개 | 누적 영역차트 (렌탈·라이선스·기타), 12개월 | 범주색 3 | 선차트 → 누적영역 |
| 만료 예정 | 조치 필요 목록 | 구간 카운트 + 표 5행 | 상태색 | ⚠ 차트 → 표 |
| 전수조사 진행률 | 한도 대비 단일 비율 | 미터 + 참여자 수 | 단일 색조 트랙 | 신설 |
| 티켓 현황 | 상태별 카운트 | KPI 4칸 (접수대기·처리중·SLA초과·이번주완료) | 상태색 | 신설 |
| 대여 현황 | 현재값 + 경고 | 스탯 타일 (대여중 / 연체 강조) | 상태색 | 신설 |
| 라이선스 정합성 | 초과 경고 | 스탯 타일 + 초과 종수 | 상태색 | 신설 |

- **V1** — 축은 하나만. 이중 축(왼쪽 금액 / 오른쪽 건수) 차트를 만들지 않는다. 척도가 다른 두 지표는 차트 두 개 로 나눈다.
- **V2** — 범주 색은 고정 순서로 배정하고 순환시키지 않는다. 필터로 계열이 줄어도 남은 계열의 색이 바뀌지 않아야 한다 — 색은 순위가 아니라 대상 을 따른다.
- **V3** — 계열이 2개 이상이면 범례를 항상 두고, 4개 이하는 직접 라벨도 붙인다. 색만으로 식별하게 하지 않는다.
- **V4** — 7개를 넘는 범주는 색을 늘리지 않는다. 자산 종류가 10개면 상위 6 + “기타”로 접거나 표로 바꾼다.
- **V5** — 상태색(정상·경고·위험)은 예약색이다. 범주 4번째 색으로 재사용하지 않고, 항상 라벨과 함께 쓴다.
- **V6** — 차트 텍스트는 계열색이 아니라 텍스트 색을 쓴다. 값·축·범례 글자는 잉크 색, 색은 마크에만.
- **V7** — 모든 차트에 호버 툴팁을 기본 제공한다. 스탯 타일만 예외. 모바일에서는 탭으로 동작해야 한다.
- **V8** — 표 보기를 제공한다. 차트마다 “표로 보기” 전환을 두어 색에 의존하지 않는 경로를 남긴다.
- **V9** — 테마는 두 모드를 각각 설계한다. 다크모드는 라이트를 반전한 게 아니라 같은 색 램프에서 다시 고른 단계다. (디자인 테마 적용 시점의 과제)

## §3 Phase 7 — 반응형 QA 체크리스트

화면이 아니라 검증 항목이다. 개발 완료 후 이 목록으로 통합 QA를 수행한다.

### 브레이크포인트 전환

- [ ] 목록(P-1) 테이블이 <768에서 카드 리스트로 전환 되고, 카드에 식별자·상태·속성 2개까지만 표시되는가
- [ ] 칸반(S-600)이 <768에서 상태 탭 + 리스트 로 전환되고 드래그가 비활성되는가
- [ ] 트리+상세(P-4)가 <768에서 드릴다운 (트리 → 선택 시 상세 전환)으로 동작하는가
- [ ] 대시보드 다단 위젯이 <768에서 1열 스택 되고 KPI는 2×2로 접히는가
- [ ] 임직원 하단 탭이 프로세스 설정에 따라 3개/4개로 균등 분할 되고 빈 칸이 생기지 않는가 (C4)
- [ ] 폼(P-3)이 <768에서 1열 + 하단 고정 액션 바 로 바뀌는가
- [ ] 가로 스크롤이 테이블/차트 컨테이너 내부에서만 발생하고 body는 절대 좌우로 움직이지 않는가
- [ ] 라이선스 상세(S-532) 탭 5개가 좁은 화면에서 가로 스크롤 로 접근 가능한가
