# 14. 구현 변경 이력 (설계 외 항목)

> 이 문서는 `01~13` 설계문서가 다루는 **자산관리 도메인 기능 설계**와 무관하지만,
> 실제 구현 과정에서 발생한 변경/수정 사항을 누락 없이 추적하기 위한 이력 문서입니다.
>
> 아래에 해당하는 항목을 여기에 기록합니다.
> - 자산관리 도메인 기능이 아닌 **앱 전체 공통 인프라** 수정 (레이아웃, 라우팅, 인증 등)
> - **개발 환경 설정**(로컬 HTTPS, 인증서, 프록시 등) 관련 변경
> - **운영 데이터 보정**(시드 데이터, 동기화 누락 등) 등 설계 결정이 아닌 운영성 조치
> - 화면 비율·간격 등 **설계문서가 다루지 않는 수준의 UI 미세조정**
> - 기타 "구현은 했지만 특정 화면 설계서(S-xxx)에 넣기엔 범위가 안 맞는" 모든 변경
